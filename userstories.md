# User Stories

## Sustainability Manager

### US-01

As a Sustainability Manager, I want to view my organization's total cloud carbon emissions so that I can track environmental impact.

### US-02

As a Sustainability Manager, I want to monitor historical emission trends so that I can evaluate sustainability progress over time.

### US-03

As a Sustainability Manager, I want to generate ESG reports so that I can share sustainability insights with stakeholders.

---

## Cloud Engineer

### US-04

As a Cloud Engineer, I want to identify high-emission resources so that I can optimize infrastructure usage.

### US-05

As a Cloud Engineer, I want to receive carbon and cost optimization recommendations so that I can improve operational efficiency.

### US-06

As a Cloud Engineer, I want to compare resource utilization across services so that I can make informed infrastructure decisions.

---

## DevOps Engineer

### US-07

As a DevOps Engineer, I want to perform sustainability checks before deployment so that environmentally inefficient releases can be avoided.

### US-08

As a DevOps Engineer, I want to view projected emission impacts of planned deployments so that I can make sustainable deployment decisions.

---

## Executive / Leadership Team

### US-09

As an Executive, I want to view an overall Green Score so that I can quickly assess the organization's sustainability performance.

### US-10

As an Executive, I want access to high-level dashboards and KPIs so that I can track sustainability goals and business impact.

---

## System Administrator

### US-11

As a System Administrator, I want to manage user access and permissions so that platform security is maintained.

### US-12

As a System Administrator, I want reliable data storage and reporting capabilities so that users can access accurate sustainability information.

---

## AI & Analytics Module

### US-13

As a User, I want AI-generated forecasts of future emissions so that I can proactively plan sustainability initiatives.

### US-14

As a User, I want automated recommendations based on usage patterns so that I can reduce both carbon emissions and cloud costs.
